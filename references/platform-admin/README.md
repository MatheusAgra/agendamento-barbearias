# Referência aprovada — painel da plataforma

`overview-approved.png` é a segunda proposta visual, aprovada explicitamente pelo usuário em 11/11/2026. Público: donos e gerentes da plataforma, responsáveis por barbearias, assinaturas e cobranças.

Origem: imagem gerada nesta conversa pela ferramenta integrada de imagens. Inspiração consultada no navegador integrado: [Vael Fintech App, no Recent](https://recent.design/i/vwi94zh-vael-fintech-app). A composição é uma proposta gerada para este projeto, não uma captura do produto citado.

Direção: grafite, textos claros, azul suave, números grandes, indicadores em faixa aberta, gráfico e cobranças lado a lado, lista de barbearias abaixo.

Nomes, valores, planos, percentuais, estados, identidade provisória e funções sugeridas são ilustrativos. A aprovação desta imagem confirma a direção visual, sem aprovar regras comerciais. A assinatura mensal com pagamento confirmado antes do cadastro continua sendo a regra existente.
