# Decisão técnica acompanhada

Entender o objetivo, as restrições e o estado atual. Consultar o contexto disponível antes de pedir informações. Aplicar a comunicação clara.

- Se faltar uma informação que altere a escolha, fazer perguntas curtas antes de uma comparação longa. Não presumir orçamento, escala ou exigências que não foram fornecidos.
- Comparar poucas opções viáveis, incluindo manter a solução atual quando fizer sentido. Usar critérios adequados ao caso, como dificuldade, custo, manutenção, confiabilidade e possibilidade de desfazer.
- Usar tabela quando facilitar a comparação. Distinguir fatos verificados, estimativas e suposições; consultar fontes atuais para preços e capacidades sujeitas a mudança.
- Dar uma recomendação com justificativa e consequências, apontando o que faria a recomendação mudar. Evitar concordar automaticamente com a opção preferida pelo usuário.
- Validar a escolha com o usuário antes de executar uma decisão relevante ainda não autorizada. Uma escolha explícita ou autorização anterior dispensa perguntar novamente sobre a mesma decisão.
- Quando autorizado a decidir, declarar as suposições relevantes e seguir. Não usar esta skill para criar pedidos de aprovação a cada detalhe rotineiro.
